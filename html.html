دليل المطوّر العربي

مرجع وسوم HTML

دليل عملي لأهم وسوم HTML: وظيفة كل وسم، ومثال بسيط، وملاحظات تساعدك تختار الوسم المناسب أثناء بناء المواقع.

شرح باللغة العربية أمثلة قابلة للنسخ بحث مباشر متوافق مع الهاتف والكمبيوتر

التنقّل بين الأقسام

بنية الصفحة النصوص والعناوين الوسوم الدلالية الروابط والصور القوائم الجداول النماذج عناصر تفاعلية وسوم أخرى وسوم قديمة

إزاي تستخدم الدليل؟

ابحث باسم الوسم أو وظيفته، مثل article أو «رابط». الأمثلة المختارة توضح الاستخدام الأساسي، وليست بديلًا عن توثيق كل الخصائص الممكنة.

معلومة مهمة: الوسوم الدلالية مثل main وarticle تصف معنى المحتوى. أما div فهو حاوية عامة، ولا يضيف معنى دلاليًا وحده.
جاري التحميل

بنية الصفحة

العناصر الأساسية التي تساعد المتصفح على فهم مستند HTML.

<!DOCTYPE html>

أساسي

يخبر المتصفح أن المستند يستخدم معيار HTML الحديث.

مثال
<!DOCTYPE html>

<html>

أساسي

العنصر الجذر الذي يحتوي على بقية عناصر الصفحة. الخاصية lang تحدد لغة المحتوى.

مثال
<html lang="ar" dir="rtl">
  ...
</html>

<head>

يحتوي على معلومات الصفحة، مثل العنوان والوصف وروابط ملفات CSS؛ ولا يعرض معظم محتواه داخل الصفحة نفسها.

مثال
<head>
  <title>موقعي</title>
</head>

<body>

يحتوي على المحتوى الذي يظهر داخل صفحة الويب، مثل النصوص والصور والأزرار.

مثال
<body>
  <h1>أهلًا بك</h1>
</body>

<title>

يحدد عنوان المستند الذي يظهر عادةً في تبويب المتصفح ونتائج البحث.

مثال
<title>تعلم HTML</title>

<meta>

يقدم بيانات وصفية، مثل ترميز الأحرف ووصف الصفحة وإعداد عرض الهاتف.

مثال
<meta charset="UTF-8">
<meta name="viewport"
 content="width=device-width, initial-scale=1">

<link>

يربط المستند بملف خارجي، مثل ملف CSS أو أيقونة الموقع.

مثال
<link rel="stylesheet" href="style.css">

<style>

يحتوي على قواعد CSS داخل صفحة HTML نفسها.

مثال
<style>
  p { color: teal; }
</style>

<script>

يضمّن JavaScript داخل الصفحة أو يربط ملفًا خارجيًا لتنفيذ وظائف تفاعلية.

مثال
<script src="app.js" defer></script>

<noscript>

يعرض محتوى بديلًا عندما تكون JavaScript معطلة أو غير مدعومة.

مثال
<noscript>فعّل JavaScript لاستخدام كل الميزات.</noscript>

النصوص والعناوين

لعرض العناوين والفقرات والتأكيد والاقتباسات والمحتوى النصي.

<h1> ... <h6>

عناوين بمستويات هرمية من الأعلى أهمية إلى الأقل. اختر المستوى حسب بنية المحتوى، وليس حجم الخط فقط.

مثال
<h1>عنوان الصفحة</h1>
<h2>قسم رئيسي</h2>
<h3>عنوان فرعي</h3>

<p>

ينشئ فقرة نصية.

مثال
<p>هذه فقرة في الصفحة.</p>

<br>

ينشئ انتقالًا إلى سطر جديد داخل النص، مثل عنوان أو عنوان بريدي. لا تستخدمه لصنع مسافات كبيرة بين العناصر.

مثال
السطر الأول<br>
السطر الثاني

<hr>

يمثل فاصلًا موضوعيًا بين أجزاء المحتوى، ويمكن تغيير مظهره باستخدام CSS.

مثال
<p>الموضوع الأول</p>
<hr>
<p>الموضوع الثاني</p>

<strong>

يشير إلى أهمية قوية للنص، وغالبًا يظهر بخط عريض.

مثال
<strong>تحذير مهم!</strong>

<em>

يضيف تأكيدًا دلاليًا إلى النص، وغالبًا يظهر مائلًا.

مثال
هذا أمر <em>مهم جدًا</em>.

<b>

يلفت الانتباه إلى النص من دون أن يضيف معنى الأهمية مثل strong.

مثال
<b>مصطلح مهم</b>

<i>

يميز نصًا بصوت أو اصطلاح مختلف، وغالبًا يظهر مائلًا.

مثال
<i>Homo sapiens</i>

<u>

يعرض نصًا عليه علامة أو خط أسفل النص؛ لا تستخدمه بدلًا من تنسيق الروابط.

مثال
<u>كلمة عليها علامة</u>

<mark>

يميز جزءًا من النص لأنه ذو صلة بالسياق، وغالبًا يظهر بخلفية ملونة.

مثال
ابحث عن <mark>الكلمة المهمة</mark>.

<small>

للملاحظات الجانبية أو الطباعة الصغيرة، مثل معلومات الحقوق.

مثال
<small>جميع الحقوق محفوظة.</small>

<del>

يمثل نصًا حُذف من المستند، وغالبًا يظهر مشطوبًا.

مثال
السعر: <del>200 جنيهًا</del>

<ins>

يمثل نصًا أُضيف إلى المستند، وغالبًا يظهر تحته خط.

مثال
<ins>السعر الجديد 150 جنيهًا</ins>

<sub>

يعرض نصًا منخفضًا قليلًا، مثل الأرقام في الصيغ الكيميائية.

مثال
H<sub>2</sub>O
H2O

<sup>

يعرض نصًا مرتفعًا قليلًا، مثل الأسس الرياضية.

مثال
x<sup>2</sup>
x2

<abbr>

يمثل اختصارًا. يمكن استخدام title لكتابة المعنى الكامل الذي قد يظهر كتلميح عند تمرير المؤشر.

مثال
<abbr title="HyperText Markup Language">
  HTML
</abbr>

<blockquote>

يمثل اقتباسًا طويلًا من مصدر آخر. يمكن إضافة رابط المصدر في الخاصية cite.

مثال
<blockquote cite="https://example.org">
  المعرفة قوة.
</blockquote>

<q>

يمثل اقتباسًا قصيرًا داخل السطر، وقد يضيف المتصفح علامات اقتباس تلقائيًا.

مثال
<p>قال: <q>أهلًا بك</q>.</p>

<code>

يمثل مقطعًا من الكود البرمجي داخل النص.

مثال
<code>console.log("Hello")</code>

<pre>

يعرض نصًا يحافظ على المسافات والأسطر المكتوبة، ويُستخدم كثيرًا مع أمثلة الكود.

مثال
<pre>
السطر الأول
    السطر الثاني
</pre>

<kbd>

يمثل إدخالًا من لوحة المفاتيح.

مثال
اضغط <kbd>Ctrl</kbd> + <kbd>S</kbd> للحفظ.

<samp>

يمثل عينة من ناتج برنامج أو نظام.

مثال
<samp>تم الحفظ بنجاح</samp>

<var>

يمثل متغيرًا في معادلة أو برنامج.

مثال
<var>x</var> = 10

<span>

حاوية عامة داخل السطر، مفيدة لتنسيق جزء من النص باستخدام CSS أو استهدافه برمجيًا.

مثال
<p>لون هذه <span class="accent">الكلمة</span>.</p>

الوسوم الدلالية وتنظيم الصفحة

تصف وظيفة أجزاء الصفحة وتجعل بنيتها أوضح للمطورين وأدوات الوصول.

<header>

يمثل مقدمة صفحة أو قسم، وقد يحتوي على عنوان أو شعار أو أدوات تنقل.

مثال
<header>
  <h1>موقعي</h1>
</header>

<nav>

يحتوي على مجموعة روابط التنقل الرئيسية أو المهمة.

مثال
<nav aria-label="القائمة الرئيسية">
  <a href="index.html">الرئيسية</a>
</nav>

<main>

يحتوي على المحتوى الرئيسي والفريد للصفحة. عادةً يوجد عنصر main واحد ظاهر في الصفحة.

مثال
<main>
  <h1>محتوى الصفحة</h1>
</main>

<section>

يجمع محتوى مرتبطًا بموضوع واحد، وغالبًا يكون له عنوان.

مثال
<section>
  <h2>مميزات الموقع</h2>
  <p>شرح المميزات هنا.</p>
</section>

<article>

يمثل محتوى مستقلًا نسبيًا، مثل مقالة أو تدوينة أو منشور في موقع تواصل اجتماعي.

مثال
<article>
  <h2>عنوان المنشور</h2>
  <p>محتوى المنشور...</p>
</article>

<aside>

يحتوي على محتوى جانبي مرتبط بالمحتوى الأساسي، مثل صندوق معلومات أو روابط ذات صلة.

مثال
<aside>
  <h2>مقالات ذات صلة</h2>
</aside>

<footer>

يمثل تذييل الصفحة أو القسم، وقد يحتوي على حقوق النشر وروابط التواصل.

مثال
<footer>
  <small>© 2026 حقوق النشر</small>
</footer>

<address>

يمثل معلومات التواصل المتعلقة بالمؤلف أو الجهة المسؤولة عن أقرب محتوى أو الصفحة، وليس أي عنوان عشوائي بالضرورة.

مثال
<address>
  البريد:
  <a href="mailto:dev@example.com">راسلنا</a>
</address>

<div>

حاوية عامة لتجميع العناصر وتنسيقها، عندما لا يكون هناك وسم دلالي أنسب.

مثال
<div class="card">
  محتوى البطاقة
</div>

<figure>

يجمع محتوى مستقلًا مثل صورة أو رسم أو مخطط أو مثال كود.

مثال
<figure>
  <img src="photo.jpg" alt="منظر طبيعي">
  <figcaption>منظر طبيعي</figcaption>
</figure>

<figcaption>

يضيف شرحًا أو عنوانًا لمحتوى داخل figure.

مثال
<figcaption>صورة توضيحية للدرس</figcaption>

الروابط والصور والوسائط

<a>

ينشئ رابطًا إلى صفحة أو ملف أو جزء داخل الصفحة أو عنوان بريد إلكتروني.

مثال
<a href="about.html">عن الموقع</a>
<a href="mailto:dev@example.com">راسلنا</a>

<img>

يعرض صورة. استخدم src للمصدر وalt لوصف الصورة عند الحاجة.

مثال
<img src="logo.png" alt="شعار الموقع">

<map>

يربط صورة بمجموعة مناطق قابلة للنقر باستخدام area.

مثال
<img src="map.jpg" usemap="#my-map" alt="خريطة">
<map name="my-map">
  <area shape="rect" coords="0,0,100,100"
        href="place.html" alt="مكان">
</map>

<area>

يحدد منطقة قابلة للنقر داخل صورة مرتبطة بعنصر map. من أشكاله rect وcircle وpoly.

مثال
<area shape="circle" coords="80,80,30"
      href="details.html" alt="تفاصيل المنطقة">

الإحداثيات تُقاس داخل الصورة، ويجب أن تتطابق مع أبعادها.

<audio>

يضمّن ملفًا صوتيًا مع إمكانية إظهار أدوات التشغيل.

مثال
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  متصفحك لا يدعم الصوت.
</audio>

<video>

يعرض فيديو داخل الصفحة. أضف controls لإظهار أدوات التشغيل.

مثال
<video controls width="400">
  <source src="video.mp4" type="video/mp4">
  متصفحك لا يدعم الفيديو.
</video>

<source>

يحدد ملفًا بديلًا أو مصدرًا لوسائط مثل الصوت والفيديو أو الصور المتجاوبة.

مثال
<source src="video.mp4" type="video/mp4">

<track>

يضيف مسارات نصية، مثل الترجمة أو التعليقات التوضيحية للفيديو والصوت.

مثال
<track src="captions-ar.vtt" kind="subtitles"
       srclang="ar" label="العربية">

<iframe>

يعرض صفحة ويب أخرى داخل إطار في الصفحة الحالية. استخدمه فقط مع مصادر موثوقة واضبط الأمان عند الحاجة.

مثال
<iframe src="https://example.org"
        title="صفحة توضيحية"></iframe>

<svg>

يُستخدم لإنشاء رسومات متجهة قابلة للتكبير دون فقدان الوضوح.

مثال
<svg viewBox="0 0 100 100" role="img"
     aria-label="دائرة">
  <circle cx="50" cy="50" r="40" fill="teal"></circle>
</svg>

<canvas>

يوفر مساحة للرسم بواسطة JavaScript، مثل الرسومات والألعاب ثنائية الأبعاد.

مثال
<canvas id="board" width="300" height="150">
  مساحة رسم
</canvas>

القوائم

<ul>

ينشئ قائمة غير مرتبة، وتظهر عناصرها عادةً بعلامات نقطية.

مثال
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol>

ينشئ قائمة مرتبة بالأرقام أو ترتيب آخر.

مثال
<ol>
  <li>تعلم HTML</li>
  <li>تعلم CSS</li>
</ol>

<li>

يمثل عنصرًا داخل قائمة ul أو ol.

مثال
<li>JavaScript</li>

<dl>

ينشئ قائمة وصفية تربط المصطلحات بتعريفاتها أو أوصافها.

مثال
<dl>
  <dt>HTML</dt>
  <dd>لغة وصف بنية الويب.</dd>
</dl>

<dt>

يمثل المصطلح أو الاسم داخل قائمة وصفية dl.

مثال
<dt>CSS</dt>

<dd>

يمثل وصف المصطلح أو تفاصيله داخل قائمة وصفية.

مثال
<dd>لغة تنسيق صفحات الويب.</dd>

الجداول

<table>

ينشئ جدولًا للبيانات المنظمة، وليس لتخطيط الصفحة بالكامل.

مثال
<table>
  <tr><th>الاسم</th><th>الدرجة</th></tr>
  <tr><td>علي</td><td>95</td></tr>
</table>

<caption>

يضيف عنوانًا للجدول.

مثال
<caption>درجات الطلاب</caption>

<thead>

يجمع صفوف رأس الجدول.

مثال
<thead>
  <tr><th>الاسم</th></tr>
</thead>

<tbody>

يجمع الصفوف الأساسية التي تحتوي على بيانات الجدول.

مثال
<tbody>
  <tr><td>علي</td></tr>
</tbody>

<tfoot>

يجمع صفوف ملخص أو تذييل الجدول، مثل الإجمالي.

مثال
<tfoot>
  <tr><td>الإجمالي</td></tr>
</tfoot>

<tr>

ينشئ صفًا داخل الجدول.

مثال
<tr>...</tr>

<th>

ينشئ خلية عنوان لصف أو عمود. يمكن تحديد نطاق العنوان باستخدام scope.

مثال
<th scope="col">الاسم</th>

<td>

ينشئ خلية بيانات عادية داخل صف الجدول.

مثال
<td>خالد</td>

النماذج وإدخال البيانات

تُستخدم لإنشاء تسجيل الدخول والبحث والتواصل وغيرها. المثال هنا توضيحي ولا يرسل بيانات إلى خادم.

<form>

يجمع عناصر إدخال البيانات، ويمكن تحديد طريقة الإرسال والوجهة باستخدام خصائص مثل method وaction.

مثال
<form action="/signup" method="post">
  ...
</form>

<label>

يضيف تسمية واضحة لحقل الإدخال، ويمكن ربطه بمعرّف الحقل باستخدام for.

مثال
<label for="email">البريد الإلكتروني</label>
<input id="email" type="email">

<input>

ينشئ حقل إدخال. تتغير وظيفته حسب type مثل text وemail وpassword وcheckbox.

مثال
<input type="email" id="email"
       name="email" required>

<textarea>

ينشئ حقلًا لكتابة نص متعدد الأسطر، مثل رسالة التواصل.

مثال
<textarea name="message" rows="4"></textarea>

<button>

ينشئ زرًا يمكن الضغط عليه. داخل نموذج، حدد type بوضوح مثل button أو submit.

مثال
<button type="button">اضغط هنا</button>

<select>

ينشئ قائمة خيارات منسدلة.

مثال
<select name="level">
  <option value="beginner">مبتدئ</option>
  <option value="advanced">متقدم</option>
</select>

<option>

يمثل خيارًا داخل select أو بعض عناصر الاختيار الأخرى.

مثال
<option value="html">HTML</option>

<optgroup>

يجمع الخيارات المتشابهة داخل قائمة الاختيار.

مثال
<optgroup label="لغات الويب">
  <option>HTML</option>
  <option>CSS</option>
</optgroup>

<fieldset>

يجمع عناصر نموذج مترابطة في مجموعة واحدة.

مثال
<fieldset>
  <legend>بيانات الحساب</legend>
  ...
</fieldset>

<legend>

يحدد عنوانًا لمجموعة fieldset.

مثال
<legend>بيانات الحساب</legend>

<datalist>

يوفر قائمة اقتراحات لحقل إدخال مرتبط عبر الخاصية list.

مثال
<input list="languages" name="language">
<datalist id="languages">
  <option value="HTML">
  <option value="JavaScript">
</datalist>

<output>

يمثل نتيجة حساب أو إجراء داخل نموذج.

مثال
<output name="result">10</output>

<progress>

يعرض تقدم مهمة، مثل تحميل ملف.

مثال
<progress value="70" max="100">70%</progress>

<meter>

يعرض قيمة ضمن نطاق معروف، مثل نتيجة أو مستوى مساحة القرص؛ ليس بديلًا لشريط تقدم مهمة.

مثال
<meter min="0" max="100" value="80">80%</meter>

العناصر التفاعلية

<details>

ينشئ عنصرًا يمكن فتحه وإغلاقه لإظهار تفاصيل إضافية دون الحاجة إلى JavaScript في الاستخدام الأساسي.

مثال
<details>
  <summary>ما هي HTML؟</summary>
  لغة لوصف بنية صفحات الويب.
</details>

<summary>

يمثل العنوان القابل للنقر داخل details.

مثال
<summary>عرض الإجابة</summary>

<dialog>

يمثل مربع حوار أو نافذة حوارية. يمكن فتحه وإغلاقه بوسائل HTML وJavaScript.

مثال
<dialog open>
  <p>مرحبًا بك</p>
</dialog>

<time>

يمثل تاريخًا أو وقتًا بصيغة يمكن للبرامج فهمها باستخدام datetime.

مثال
<time datetime="2026-10-10">
  10 أكتوبر 2026
</time>

<template>

يحتوي على HTML لا يُعرض مباشرة عند تحميل الصفحة، ويمكن نسخه وإدراجه باستخدام JavaScript.

مثال
<template id="card-template">

وسوم أخرى مفيدة

<wbr>

يحدد موضعًا يمكن للمتصفح كسر الكلمة أو السطر عنده إذا احتاج إلى ذلك.

مثال
verylongword<wbr>thatcanbreak

<bdi>

يعزل اتجاه النص عن اتجاه النص المحيط، وهو مفيد عند عرض أسماء أو نصوص مجهولة الاتجاه في صفحة عربية.

مثال
<p>اسم المستخدم: <bdi>Alex_123</bdi></p>

<bdo>

يفرض اتجاه عرض النص عبر الخاصية dir، مثل ltr أو rtl.

مثال
<bdo dir="ltr">Hello 123</bdo>

<data>

يربط نصًا ظاهرًا بقيمة آلية عبر الخاصية value.

مثال
<data value="SKU-204">القميص الأزرق</data>

<ruby>

متخصص

يستخدم لعرض تعليقات أو إرشادات نطق صغيرة بجانب النص، خصوصًا في الكتابات شرق الآسيوية.

مثال
<ruby>漢 <rt>kan</rt></ruby>

<rt>

متخصص

يحدد نص التعليق أو النطق داخل ruby.

مثال
<rt>kan</rt>

<rp>

متخصص

يوفر علامات احتياطية للمتصفحات التي لا تدعم تعليقات ruby.

مثال
<ruby>漢<rp>(</rp><rt>kan</rt><rp>)</rp></ruby>

<noscript>

يعرض رسالة أو محتوى بديلًا إذا لم تتوفر JavaScript. يمكن استخدامه أيضًا داخل head في حالات محددة.

مثال
<noscript>بعض وظائف الموقع تحتاج JavaScript.</noscript>

وسوم قديمة لا تستخدمها في المشاريع الجديدة

تظهر هنا للتعرّف عليها عند قراءة أكواد قديمة. استخدم البدائل الحديثة المناسبة.

<applet>

مهجور

كان يستخدم لتضمين برامج Java صغيرة داخل صفحة الويب. أصبح قديمًا وغير مدعوم في HTML الحديثة.

بديل مناسب
<!-- استخدم HTML وJavaScript أو تقنيات الويب الحديثة -->

<font>

مهجور

كان يتحكم في لون الخط وحجمه ونوعه داخل HTML. استبدله بقواعد CSS.

بديل
<span class="highlight">نص</span>

/* في CSS */
.highlight { color: teal; }

<center>

مهجور

كان يوسّط المحتوى. استخدم CSS بدلًا منه.

بديل
.centered { text-align: center; }

<big>

مهجور

كان يعرض النص بحجم أكبر. استخدم CSS لتحديد حجم الخط.

بديل
.large-text { font-size: 1.25rem; }

<strike>

مهجور

كان يعرض نصًا مشطوبًا. استخدم del إذا كان النص محذوفًا دلاليًا، أو CSS للمظهر فقط.

بديل
<del>سعر قديم</del>

<frameset> و<frame>

مهجوران

كانا يستخدمان لتقسيم نافذة المتصفح إلى إطارات. لم يعودا جزءًا من HTML الحديثة؛ استخدم تخطيط CSS أو iframe عند الحاجة المناسبة.

لم نعثر على وسوم مطابقة. جرّب كلمة أخرى.

نصيحة: ليس مطلوبًا حفظ كل الوسوم. تعلّم الوسوم الأساسية أولًا، ثم ارجع إلى هذا المرجع عندما تحتاج وظيفة محددة.

هذا الملف مرجع تعليمي مختصر، وليس قائمة كاملة بكل عناصر HTML وخصائصها. للحصول على التفاصيل الدقيقة، راجع توثيق MDN أو معيار HTML.
